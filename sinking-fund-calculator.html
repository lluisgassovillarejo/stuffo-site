How the calculation works

Remaining gap = target − amount already set aside, with a minimum of zero. Divide that gap by your chosen number of contributions. Each contribution is rounded up to a cent; the last is reduced if needed so the total equals the gap.

For example, $100 across three contributions becomes $33.34, $33.34 and $33.32. If you already have more than the target, the result is zero additional contributions required.

Monthly, weekly or every paycheck?

The arithmetic is the same. Choose your actual contribution dates and count them. A plan with six paydays remaining has six contributions; it does not become six monthly payments. This tool does not infer dates, interest, investment returns or changes in costs.

Use a target you can review

This calculates what your entered plan requires. It does not assess affordability or reserve money. Review the amount, the deadline or the number of contributions if the result does not fit your plan.

Stuffo's app uses a target date for its monthly suggestion. This web calculator uses a contribution count you choose, so the results need not match.
